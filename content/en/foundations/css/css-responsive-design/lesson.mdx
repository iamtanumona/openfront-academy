## Why this matters

Start with a usable small-screen layout, then add enhancements using media queries. Test zoom and text resizing.

## Example

```css
.grid { display: grid; gap: 1rem; }
@media (min-width: 48rem) { .grid { grid-template-columns: repeat(2, 1fr); } }
```

## Try it yourself

Recreate the example in your own editor. Change one part and explain the effect.

## Check your understanding

- What problem does this feature solve?
- How would you explain it to someone new to the web?

## Accessibility checkpoint

Make sure the result remains understandable when using only a keyboard or when text is enlarged.
