## Why this matters

A browser interprets HTML as a structured document. A valid document starts with a doctype and contains `html`, `head`, and `body` elements.

## Example

```html
<!doctype html>
<html lang="en">
<head><meta charset="utf-8"><title>My page</title></head>
<body><main><h1>Hello, web!</h1></main></body>
</html>
```
