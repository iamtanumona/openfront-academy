## Why this matters

Use `label` with a matching input `id`. Avoid placeholder-only labels and ensure error messages are understandable.

## Example

```html
<form>
  <label for="email">Email address</label>
  <input id="email" name="email" type="email" required>
  <button type="submit">Join</button>
</form>
```

## Accessibility checkpoint

Make sure the result remains understandable when using only a keyboard or when text is enlarged.
