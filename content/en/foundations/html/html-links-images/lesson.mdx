## Why this matters

Link labels should describe destinations. Images need alternative text when they communicate meaning; decorative images can use empty alt text.

## Example

```html
<a href="/tracks">Explore learning tracks</a>
<img src="diagram.png" alt="Three connected learning steps">
```

## Try it yourself

Recreate the example in your own editor. Change one part and explain the effect.

## Check your understanding

- What problem does this feature solve?
- How would you explain it to someone new to the web?

## Accessibility checkpoint

Make sure the result remains understandable when using only a keyboard or when text is enlarged.
